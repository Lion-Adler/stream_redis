# 📡 Resilient Multi-Symbol Market Data Streamer

Высокопроизводительный асинхронный стример рыночных данных (Orderbook и Trades) с бирж Binance и Bybit (Spot & Futures). Спроектирован для работы в режиме 24/7 с автоматическим восстановлением соединений и изоляцией ошибок.

## ✨ Основные особенности

* **Multi-Exchange & Multi-Market:** Одновременная работа с Binance и Bybit, включая спотовые и фьючерсные рынки.
* **Архитектура "Shared Nothing":** Каждый поток (стаканы/сделки) работает в независимой корутине. Сбой в одном потоке не влияет на работу остальных.
* **Экспоненциальный Backoff:** Умная система переподключений для предотвращения бана по IP.
* **Zero-Leak Shutdown:** Использование `asyncio.shield()` гарантирует корректное закрытие соединений даже при `Ctrl+C`.
* **Fast Messaging:** Сериализация данных через `MsgPack` для минимизации нагрузки на Redis.

## 🛠 Технологический стек

* **Python 3.8+**
* **CCXT Pro:** WebSocket-API бирж.
* **Redis:** Брокер сообщений (Pub/Sub).
* **MsgPack:** Бинарная сериализация.

## 🚀 Логика переподключений

Система использует формулу экспоненциальной задержки:

$$T_{delay} = \min(T_{min} \cdot M^{(n-1)}, T_{max})$$

Где:
* $T_{min}$: Начальная задержка (1 сек)
* $M$: Множитель (2)
* $n$: Номер попытки
* $T_{max}$: Максимальная пауза (60 сек)
